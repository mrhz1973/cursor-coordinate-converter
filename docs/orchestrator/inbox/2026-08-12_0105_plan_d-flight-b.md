## 8. Strategia `zone_id`

**Tipo:** `string` non vuota, deterministica, **no UUID**, no random.

### Regole

1. **ED-269 V1/V2:**  
   `zone_id = canonCountry(raw.country) + ":" + canonId(source_stable_id)`  
   - `canonCountry`: trim + upper; se assente/blank → `"UNK"` + warning `missing_country`  
   - `canonId`: `String(id).trim()` (preserve case identifier, no spaces collapse beyond trim)

2. **ED-318:** stesso schema se `raw_properties.country` presente; altrimenti `"ED318:" + canonId(source_stable_id)`.

3. **WFS (`h2-wfs`):**  
   `zone_id = "WFS:" + canonId(source_stable_id)`  
   (`properties.id` già obbligatorio e unique in A)

### Collision / duplicate

- Dopo clustering, se due zone diverse collidono sullo stesso `zone_id` → **FATAL** `duplicate_zone_id` (fail-closed).
- Feature A duplicate id già bloccate in parse WFS; ED multi-volume **stesso** id = cluster legittimo, **non** collisione.

### ID mancante

- Non deve arrivare da A (WFS/ED fail in parse). Se arriva intermediate malformato → FATAL `missing_source_stable_id`.

## 9. Clustering / identità zona

### Analisi reale

| Formato | Intermediate | Chiave affidabile |
| --- | --- | --- |
| WFS | 1 feature ↔ 1 intermediate; `source_stable_id` unique | sì — `properties.id` |
| ED-269 | N intermediate con **stesso** `source_stable_id` (= identifier) | sì — identifier (+ country in raw) |
| ED-318 | tipicamente 1:1; GC non flatten in A | `source_stable_id` |

**Nome:** **non** usare come grouping key (collisioni / fusioni errate).

### Raccomandazione unica: **B2-light / hybrid**

- **WFS:** **B1** — nessuna fusione; 1 intermediate → 1 zone.  
- **ED-269/318:** clustering **solo** su `source_stable_id` (chiave source verificabile).  
- **Vietato:** grouping per `name`, per bbox, per similarità testuale.

Ordine cluster: primo incontro di `source_stable_id` nell’array A; volumi nell’ordine delle intermediate features del cluster, poi flatten geometrico stabile.

Fail-safe: senza chiave affidabile → **non** fondere.

## 10. Modello verticale

Conversione:

- `M` → `value_m = value`
- `FT` → `value_m = value * 0.3048` (esatto)
- unit assente/ignota → `value_m = null`, warning `unknown_vertical_unit`
- reference assente o non in `{AGL,AMSL}` → `reference = null`, warning `unknown_vertical_reference` (**non** inventare AGL)
- WFS `_m` → unit `M`, reference **null** (come A)

Casi:

| Caso | Semantica |
| --- | --- |
| value null | bound vuoto OK; warning soft se entrambi null |
| negativi | ammessi numericamente; warning `negative_vertical` |
| `upper_m < lower_m` (quando entrambi noti) | warning `inverted_vertical`; **non** swap automatico |
| unlimited / infinity | **non** derivabile da A oggi → non inventare; se raw string futura, rinviare |
| SFC implicito (limit assente + AGL) | **non** auto-0 in B (WU lo cita; A non lo marca) → lascia null + warning; eventuale product later |

## 11. Modello temporale

### API

```js
dflightNormalize(parseResultOrBundle, options)
// options.referenceTime: obbligatorio string ISO-8601 UTC o number epoch ms
```

- Core **richiede** `referenceTime` esplicito (fail FATAL se assente/invalid).
- Convenience opzionale (non necessaria in MVP B): `dflightNormalizeNow(x)` → wrapper `Date.now()` — **non** usata nei self-test.

### Inclusività

- Intervallo data: **`start <= t < end`** se end presente; se solo start: `t >= start` → ACTIVE o FUTURE; se solo end: `t < end` → ACTIVE o EXPIRED; nessuno → UNKNOWN (salvo permanent).
- `permanent === true` → **`ALWAYS_ACTIVE`** (ignora date/schedule per lo stato).
- Schedule: se presente e days/time parseable:
  - day `ANY` o giorno UTC di `referenceTime` ∈ days
  - time: se `start_time <= end_time` → `[start,end)`; overnight `start > end` → match se `t >= start || t < end`
  - schedule non parseable → warning; stato da sole date se possibili, else UNKNOWN
- Timestamp malformato → ignore quel bound + warning; se nessun bound utile → `UNKNOWN`
- WFS: costruisci **un** TimePeriod sintetico da `temporal_raw.valid_from/to`, `permanent=null`

Stati: `ACTIVE_NOW` | `FUTURE` | `EXPIRED` | `ALWAYS_ACTIVE` | `UNKNOWN` (nomi WU + prompt).

**ED full schedule:** leggere `raw_properties.applicability[]` (non solo `temporal_raw` truncato).

## 14. Restriction / reason

**ED whitelist restriction:** `PROHIBITED`, `REQ_AUTHORISATION`, `CONDITIONAL`, `NO_RESTRICTION` — match esatto stringa.  
Altrimenti: `restriction=null`, `restriction_known=false`, preserva `restriction_raw`.

**Reason whitelist:** `AIR_TRAFFIC|SENSITIVE|PRIVACY|POPULATION|NATURE|NOISE|FOREIGN_TERRITORY|EMERGENCY|OTHER`.  
Non in lista → esclusi da `reasons[]`, warning `unsupported_reason`, raw preservato.

**WFS:** nessun mapping enum; `restriction=null`; `restriction_raw` da A; `reasons=[]`.

Niente keyword matching.

## 17. Error / warning contract

### FATAL (`ok:false` o reject zona intera se policy strict)

- intermediate input non OK / missing `intermediate_features`
- `referenceTime` assente/invalid
- missing `source_stable_id`
- `duplicate_zone_id` post-cluster
- empty volumes dopo normalize
- geometry non convertibile
- cap zone > 5000 (stesso cap A)

### WARNING (zona ok)

- `unknown_restriction`, `unsupported_reason`
- `missing_authority` (ED senza array)
- `unknown_vertical_reference` / `unknown_vertical_unit`
- `inverted_vertical`, `negative_vertical`
- `malformed_date`, `partial_temporal`
- `missing_country`, `empty_name`
- `circle_polygonized` (informativo opzionale — preferire omit se rumoroso)
- `owner_not_authority` (WFS, una volta)

Fail-closed solo per geometria/identità/integrità.
